# Documentation Directory (`docs/`)

This directory contains formal project engineering deliverables as mandated by RUET CSE 3206 Lab 2 specifications:

- **`Requirement_Report.pdf`**: The complete 16-section Project Design Report (Cover Page, Problem Statement, Stakeholders, 12 FRs, 10 NFRs, 5 User Stories, Waterfall Model Justification & Comparisons, MVP Architecture, GitHub Evidence, Challenges, and Conclusion).
- **Architecture Diagrams**: High-resolution exports of system workflows and state machine diagrams.
