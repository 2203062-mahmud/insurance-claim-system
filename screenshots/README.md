# Prototype Screenshots Directory (`screenshots/`)

This directory is designated for high-resolution verification screenshots of the running Minimum Viable Product (MVP), to be captured during testing and included in the Project Design Report:

1. **`01_policyholder_dashboard.png`**: Policyholder home view displaying active insurance policies and personal claim status tracking.
2. **`02_claim_submission_form.png`**: Multi-step claim filing wizard with validation and evidence attachment.
3. **`03_adjuster_review_queue.png`**: Claims Adjuster inspection workspace with status and priority filtering.
4. **`04_claim_adjudication_modal.png`**: Adjuster adjudication console with deductible subtraction and Approve/Reject controls.
5. **`05_audit_trail_history.png`**: Chronological audit trail timeline showing immutable actor actions and state transitions.
6. **`06_executive_analytics.png`**: Administrator dashboard showing settlement ratios and financial totals.
